# レンタルスタジオ・貸し会議室 1店舗目黒字化ガイド

これは、FC加盟や多店舗チェーンを前提とした教材ではありません。

副業として、あるいは独立の第一歩として、
**1店舗目を着実に黒字化したい方**のための内容です。

副業でも、会社員でも、未経験でも。

大きな在庫を抱える必要もなく、
何百万円もの投資をする必要もなく、
現実的に月5万〜10万円のストック収入を作れる可能性がある。

それが「レンタルスタジオ・貸し会議室」というビジネスです。

飲食店のような重たいオペレーションもなく、
人を常駐させる必要もありません。

物件を選び、備品を揃え、
予約と入室の仕組みを整えてしまえば、
基本的に無人で回るビジネスモデルです。

ただし、適当に始めてうまくいくほど甘い世界でもありません。

実際にレンタルスペース業界では、
こんな理由で撤退している人が後を絶ちません。

- 物件選びを間違えて、集客しても利益が残らない
- 騒音トラブルを見落として、クレーム対応に追われる
- 競合や価格設定を読み違えて、そもそも予約が入らない
- ポータルサイトに頼りすぎて、売上は立つのに手残りが少ない

だからこそ、このコンテンツには**「僕自身が6拠点を実際に回して得た数字と判断基準」だけ**をまとめました。

伝聞でも、業界の一般論でもありません。
自分の口座を実際に出入りしたお金から逆算した内容です。

コンサルタントでも、運営代行業者でもありません。

現在、**兵庫・大阪エリアでレンタルスタジオ4拠点・貸し会議室2拠点、計6拠点を直営で運営している現役オーナー**です。

自分の資金で物件を借り、自分で内見し、自分で設営してきました。
だからこのコンテンツに書いてあるのは、机上の計算ではなく、
**実際の入出金データから逆算した知見**です。

事業の安定性と将来性が認められ、日本政策金融公庫からの融資も実現しました。
「副業・個人レベルの話」ではなく、金融機関にも認められた、
本業として成立する事業モデルとして構築しています。

**主な実績**

- 初期費用70万円以内で、競合エリアでも開業1ヶ月目から黒字化
- ロードサイド物件でも定期利用で曜日を埋め、安定運営を実現
- 公式LINEと自社決済の導線構築により、利益率を約30%改善
- 日本政策金融公庫からの融資実績あり（事業性・収益性が認められた証明）
- 現在は月2〜3時間ほどの稼働で、毎月10万円以上の利益が残る状態

順風満帆だったわけではありません。
物件選定で悩んだことも、問い合わせで何度も断られたことも、
出店したのに予約が入らず苦戦したこともあります。

**その失敗も含めて、そのまま書いています。**

### 物件選定の心構え

「レンタルスタジオを始めよう！」といざ意気込んでみても、一番躓きやすいのが物件選定です。正直なところ、すぐには良い物件は拝むことはできません。だからこそ覚えておいて欲しい「心構え」をまとめました。

> 🎥 **【動画04】物件選定の心構え**

**文字で読みたい方はこちら↓**

#### 原則① レンタルスペースはロケーションが9割

レンタルスペースはブランドではなく、場所の利便性で選ばれるビジネスモデルです。シャネルやエルメスのようにブランド価値で高値がつくビジネスとは異なり、駅からの近さやアクセスの良さがそのまま収益に直結します。内装がどれだけ豪華でも、駅から遠ければ集客は見込めません。

#### 原則② 最初から良い物件を見つけるのは難しい

特に関東などの激戦区では、条件の合う物件に出会えることは稀です。「すぐ見つかるはず」という期待は持たず、良い物件が出たときにすぐ動けるよう、常時ウォッチする習慣を持つことが重要です。

常時ウォッチしておくべきサイト
→ [アットホーム](https://www.athome.co.jp/)

※調べ方については「物件選定の手元動画」を参照

#### 原則③ 物件を探す範囲は広めに持つ

東京・大阪だけに絞っていては選択肢が極端に狭まります。周辺の都道府県も視野に入れて広範囲で探すことで、条件に合う物件に出会える確率が上がります。

#### 原則④ 断られることを前提にする

レンタルスペースは「また貸し」と見なされ、用途NGとなるケースが非常に多いです。断られることは例外ではなく当たり前と割り切り、数をこなしていく姿勢が大切です。

#### なぜ個人でも勝てるのか

「ブランド価値が低いなら、そもそも旨みがないのでは？」と思われるかもしれません。
ですが、**これがそのまま個人の勝ち筋になります。**

大手企業が参入してくるのは、規模の経済やブランド力・資本力が効く市場です。
レンタルスペースは規模の経済が効きにくく、**高い人件費や固定費を投下してまで、1物件あたり月5〜7万円の利益を取りに行くことはしません。**

一方、個人単位なら話は別です。

- 1つのスペースにきちんと注力できる
- 初期投資が50万〜70万円、多くても100万円以下で始められる
- その小額投資に対して、月5万〜7万円が毎月安定的に入ってくる
- 清掃も売上管理も外注化できるため、作業で手が取られることが少ない

ただし「完全放置でいい」わけではありません。
戦略の見直し、新規物件の選定、**そのエリアに新たな競合が増えていないかのチェック**は、常に自分で見ておく必要があります。

まとめると、大手は1物件あたりの利益が小さすぎて人件費をかけて参入するメリットがなく、規模の経済も効きにくい。だからこそ**個人が入り込める領域として残り続けている**、ということです。

### 物件選定の基本｜守るべき7つの条件

物件選定を行う上で、必ず守っていただきたい条件を7つにまとめました。

正直、他のレンタルスペース業を営む業者はここまでこだわってやっていないです。だからこそ赤字を出してしまったり、事業継続が難しくなるパターンが多いのですが、逆に言えば、これらの条件を守っていただけることで、黒字化できる確率が一気に高まります。

ここで学んでいただく内容は、この講座のミソと言っても過言ではありません。それくらい重要なところなので、何度も見返すようにしましょう。

> 🎥 **【動画05】物件選定の基本7条件**

**文字で読みたい方はこちら↓**

#### 条件① 駅ベースで検索する

物件を探す際は、「〇〇区」「〇〇市」といったエリアではなく、**駅単位**で市場を見ていくことが重要です。

ここで見るのは**乗降者数**と**駅からの近さ**の2つで、僕はかなり厳しく見ています。

**乗降者数は1日4万人以上。**
2万人・3万人規模だとそもそも需要の上限が決まってしまっていて、収益がトントンかマイナスになりやすいです。

乗降者数は「〇〇駅 乗降者数」で検索すればすぐ出てきます。
「関西 乗降者数ランキング」「関東 乗降者数ランキング」のように調べて、**4万人以上の駅を先にリストアップしてしまう**のが効率的です。

**駅からの距離は徒歩5分以内が絶対条件。**
インスタベースやスペースマーケットのような検索サイトでは、徒歩7分・10分だとアクセスが悪いとみなされて上位表示されにくくなります。

さらに利用者側の事情として、

- 着替えや機材など**荷物が多い**
- 「スタジオ直接集合で」と**集合場所として使われる**

という使われ方をするため、駅からの近さはそのまま予約数に響きます。

#### 条件② 広さは15平米以上を目安にする

検索サイトの仕様上10平米以上で絞り込むことになりますが、**正直10平米だとダンスをする上で1人でも狭く感じます。**

僕がアットホームで検索するときも、15平米や20平米では絞り込めないため10平米以上で検索し、そこから実物を見て15平米以上のものを選んでいます。

広さによってターゲットと用途がまったく変わることを意識してください。

| | 小箱（15〜30平米） | 大箱（50平米以上） |
|---|---|---|
| ターゲット | 個人・少人数 | 教室・団体 |
| 利用形態 | **単発利用がメイン** | **定期利用がメイン** |
| 主な用途 | 個人練習、ボイトレ、ピラティス、少人数クラス | ダンス教室、体操教室、空手道場、稽古、撮影 |

30平米は少し中途半端で、大箱を狙うなら**50平米以上、できれば90平米**あると借り手がぐっと増えます。

#### 条件③ 家賃は安いほど正義

家賃は利益率に最も大きく影響する固定費です。
**どれだけ売上が高くても、家賃が高ければ利益は残りません。**

具体的にシミュレーションしてみます。

| | ケースA | ケースB |
|---|---|---|
| 売上 | 100,000円 | 100,000円 |
| 家賃 | 50,000円 | 80,000円 |
| その他経費（水道光熱費・清掃代など） | 10,000円 | 10,000円 |
| **利益** | **40,000円** | **10,000円** |
| **利益率** | **40%** | **10%** |

家賃が3万円違うだけで、**利益率が30%も変わります。**

理想は月3万〜6万円台。都内・神奈川では正直かなり見つけにくいので、東京にお住まいの方でも埼玉や神奈川の少し地方寄りのエリアまで広げてみてください。そのほうが**初期のリスクも毎月のリスクも抑えられます。**

#### 条件④ 定期借家は選ばない

物件を賃貸で借りるとき、契約には**普通借家**と**定期借家**の2種類があります。

**普通借家**は、正当な理由がない限り更新可能。借り手の権利が強く、長く安心して営業できます。

**定期借家**は、契約期間の満了で必ず終了します。仮に「続けていいよ」と言われても再契約手数料が別途かかりますし、**2年経ったら普通に「出ていってね」と言われることもあります。**

さらに効いてくるのが**売却時**です。

事業が儲かってきて「利益の3年分・4年分で売りたい」となったとき、定期借家だと買い手にとって投資回収リスクがあります。100万円で買ったのに残り1年しか運営できない、という状態は買い手にとってリスクでしかありません。

事業の継続性と売却のしやすさ、両面から**普通借家一択**です。

#### 条件⑤ 騒音トラブルにならない物件を選ぶ

僕は基本的に、**普通の住居用の賃貸はレンタルスタジオには選びません。**（貸し会議室なら話は別です）

選ぶのはこういう物件です。

- テナントが多く入っている**雑居ビル**
- **線路沿い・沿線沿い**（電車が通っているところ）
- **交通量が多いところ**

つまり、もともと音が気になりにくい環境かどうかです。

階数も重視していて、**地下・1階はかなり良い。** 2階以上でも、階下が店舗や飲食店なら大丈夫です。

そして大事なのは、**無理にダンススタジオにしないこと。**
リスクが高いと感じたら、**貸し会議室として運営する判断**に切り替えるのが一番です。

#### 条件⑥ 長方形・正方形の物件を選ぶ

L字型や三角形といった変形間取りは使い勝手が悪いので、基本的にやめておいたほうがいいです。

**ダンススタジオの場合**

壁一面に鏡を貼る必要がありますが、変形間取りだと「そもそもどこに貼るのか」という問題が起きます。鏡が途中で途切れますし、フォーメーション練習のときに**部屋の隅が欠けていると人数が入りきりません。**

**貸し会議室の場合**

机のレイアウトが組みにくく、スクリーンやホワイトボードが見えない死角が生まれます。

#### 条件⑦ 競合をリサーチした上で参入する

ここは勘違いされている方が非常に多いところです。

**競合がいる＝利益が出にくい、ではありません。**
競合の存在は、そのエリアに**確実な需要がある証明**です。

僕は最初、競合がいない場所に出店してしまい、黒字化するまでに**半年〜7ヶ月**かかりました。
一方、競合がいる場所に出したときは**1ヶ月目で黒字化**しています。

競合がいないということは、「レンタルスタジオというものがある」という認知から自分で取りにいかなければならない、ということです。そのめんどうな仕事を、わざわざ自分でやる必要はありません。

そのうえで、競合に勝つポイントを見極めます。

- 駅からの近さ
- 平米数
- 価格
- 内装・設備

競合を見た上で「自分ならここを上乗せできる」という条件を作り、**より良い選択肢をお客様に提示すること**が集客の鍵です。

4. 事前に「〇〇県 乗降者数ランキング」で調べ、**1日4万人以上の駅にだけチェック**を入れる
5. 絞り込み条件を入れる
   - 賃料上限 **10万円**（管理費含む）
   - 面積 **10平米以上**
   - 駅から **徒歩5分以内**
6. 出てきた一覧を、写真と地図で1件ずつ判定していく

##### 一覧から弾いていく判定基準

| 見えたもの | 判断 |
|---|---|
| 人が住んでいそうなマンション・アパート・一軒家 | ダンススタジオでは**選ばない**（騒音トラブル）。貸し会議室・ミーティング用途ならアリ |
| 雑居ビルかどうか判断がつかない | **地図・ストリートビューで建物を確認。** 1階が店舗で2階以上が住居なら見送り |
| スケルトン物件 | **選ばない。** コンクリート剥き出しで内装の施工費が跳ね上がる |
| 変形間取り・室内に柱がある | 鏡を貼る面が決まらないので見送り |
| 上下階・隣が学習塾や事務所 | 内見で音の確認が必須。階が離れていれば（例：4階）まだマシ |
| 徒歩5分ちょうど | **かなり選びにくい。** 徒歩1〜3分の競合が同価格で出てきたら優先順位で負ける |

##### 良さそうな物件が出たときの見方

たとえば「新長田駅 徒歩3分」の物件。
新長田はJRで約5万3千人、地下鉄で約4万3千人、**合計9万人以上**の乗降者数があります。徒歩3分で条件も良く、僕はこの物件を実際に契約しました。

ただし、**この時点ではまだ決めません。**
「この駅・このエリアで競合がどう出店していて、どれくらい予約が埋まっているのか」を必ず確認します。それが次のステップです。

### 競合調査と収支シミュレーションの手元動画

良い物件を見つけた時に必ず行うのが、
**「ここの立地ではどれくらいの売上が上がるのか？」**
というのを競合を調査して割り出すことです。

物件選定の7つの基本を押さえた上で、
この競合から割り出した収支シミュレーションが良ければ、
参入をかなり前向きに捉えていった方がいいです。

> 🎥 **【動画07】競合調査と収支シミュレーション 手元実演**

**文字で読みたい方はこちら↓**

競合調査とは、**エリアを指定した上で出てきた競合が「どれくらい儲かっているのか」まで割り出す**作業です。

##### ① インスタベースで「駅名」＋用途で検索する

レンタルスタジオを検討しているなら「ダンススタジオ」、貸し会議室を検討しているなら「貸し会議室」でカテゴリを絞ります。

##### ② 競合になり得るものだけを抜き出す

- **価格が高すぎるところは外す**（そもそも選ばれていないため参考にならない）
- **平米数が近いもの**を見る（18平米の物件を検討しているなら、20平米・26平米あたりが競合）

##### ③ 「どれくらい埋まっているか」を調べる

ポータルサイトの空き室カレンダーでは**過去にどれだけ埋まっていたかが見られません。**
そこで、競合スペースの名前をコピーして検索にかけ、**自社サイト（ホームページ）を探します。**

自社サイトの「空き状況」ページにはGoogleカレンダーが埋め込まれていることが多く、**1月・12月と過去に遡って埋まり具合を確認できます。**

> ダンススタジオは自社ホームページを持っていることが多いので、この方法が使えます。
> 見つからない場合は、ポータルの空き室カレンダーの丸・三角の数から読み取ります。

##### ④ 1時間あたりの単価を出す

パック料金しか出ていない場合は逆算します。
例：金曜1時間半で2,528円 → 1.5で割って **1時間あたり約1,500円**

##### ⑤ 月商と手残りを推定する

単価 × 埋まっているコマ数 ＝ 月商の目安。
そこから**インスタベース経由なら35%が引かれる**ことを考慮して、手残りを見ます。

##### ⑥ 競合の「穴」を探す

競合の予約ページを見ると、営業時間の制限が見えてきます。

- 18時半以降が使えない
- 21時以降の利用ができない
- 水曜・木曜は21時まで

こういう穴があれば、**そこを開けるだけで競合のお客さんをごっそり取れます。**

##### ⑦ 自分の物件が勝てるかを比較する

| 比較項目 | 競合 | 自分の候補物件 |
|---|---|---|
| 駅からの距離 | 徒歩4分 | 徒歩1〜2分 ✅ |
| 平米数 | 40平米 | 37.5平米 ≒ |
| 価格 | ― | 設定可能 |
| 設備 | ― | 上乗せ可能 |

この例なら**物件スペックで勝てているので参入OK**と判断します。

##### 補足：自社サイトを持っていない競合は狙い目

自社決済のサイトを持っていない競合は、ポータルの高い手数料を払い続けている＝**利益が取れていない可能性が高い**です。そこはつけ入る隙になります。

##### まとめ

アットホームで良さそうな物件を見つけたら、**必ずインスタベースで駅名から競合を調べ、「どれくらい予約が埋まっているか」「どれくらい利益が見込めるか」を確認してから出店する。**

このやり方は、どの駅・どのエリアでも同じです。

> 🎥 **【動画08】不動産業者への問い合わせ**

**文字で読みたい方はこちら↓**

基本方針は**「断られることが前提」**です。

一発目でNGを食らって「もう物件は見つからない、やめよう」と諦めてしまう方が本当に多いのですが、**3段階のフォールバックで交渉する**ことで、出店できる可能性を最大化できます。

なぜレンタルスタジオから聞くのかというと、**ダンススタジオのほうが収益性が高く、リピートも良いから**です。だから本命から順に、段階的に提案を下げていきます。

問い合わせの際は下記のテンプレを手元に置いて行うようにしてください。

#### 【レンタルスタジオ出店交渉】初回問い合わせの攻略テンプレ

**「断られること前提」で段階的に提案を下げていく。**
一発NGでも諦めず、3段階のフォールバックで交渉する。

**STEP 1｜まず本命を聞く**

基本的には通話で話す方が早いので、アットホームから直接問い合わせる。

その際に、シンプルに下記のように聞いてください。

> 「時間制のレンタルスタジオ（鏡付き）は出店可能ですか？」

ここでOKならかなりラッキーです。内見にいきましょう。

**STEP 2｜音の懸念が出たら → 実績＋内見提案で返す**

多くの場合、レンタルスタジオは音の懸念点があり、出店を許可されないパターンが多いです。

ですので、その不安を取り除くためにも、現地にいって実際に音漏れがあるかを確かめたい旨を伝えましょう。

> 「音漏れ対策済みで、70dB以下でのご利用に限定しています。店内にdB測定器を設置しており、お客様にもリアルタイムで確認していただける仕組みです。一度現地に伺って、実際の音の漏れ具合を確認させていただくことは可能でしょうか？問題があるようであれば出店はいたしません。」

**ポイント：** 「もし合わなければやめる」と断言することで、相手のトラブルリスクへの不安を取り除きます。

不動産業者は本来、**貸したい・借りてもらいたい**立場です。「一度スピーカーを持ち込んで70dBで測ってみて、廊下・下階・建物の外に漏れないことを確認できたら借りさせてください」と伝えれば、内見まで進めるケースは十分にあります。デシベル測定はスマホの無料アプリでできます。

**STEP 3｜それでもNGなら → 用途を下げる**

それでも断られる場合は、音が出ない貸し会議室としての利用はどうかを伝えましょう。

> 「では、音の出ない会議室利用としての出店はいかがでしょうか？企業のミーティング用途を想定しています。」

会議室は普通の事務所と同じようなものなので、騒音トラブルの心配がありません。スタジオ→会議室に用途を変えることで、**ハードルを大幅に下げられます。**

収益性はレンタルスタジオのほうが上ですが、断られて何も出せないよりは圧倒的に良い選択です。

**STEP 4｜全部NG → 潔く撤退**

ここでダメなら、そもそも又貸し・転貸に近いレンタルスペースをよく思っていないオーナーさんなので、無理に押さないようにしましょう。そこで時間を使うのであれば、次の物件に時間を使う方が効率的です。

### 内見・契約時の注意点

内見が決まったら、
「実際にここは借りても良い物件なのか」というのを調べるために、
最終チェックが必要です。

実際に内見に行ってみたら、
「匂いが気になる…」
「音漏れがかなりある…」
といったことも多々あります。

撤退という最悪なことも想定した上で内見、契約まで行うようにしましょう。

> 🎥 **【動画09】内見・契約時の注意点**

**文字で読みたい方はこちら↓**

#### 室内のチェックリスト

**【室内チェック①】広さと匂いの確認**

図面上の平米数と実際の体感は異なることが多く、特にダンスや運動用途では静止時より広いスペースが必要になります。トイレや収納が平米数に含まれていて実際に動ける範囲が狭いケースもあるため、必ず体感で確認してください。

匂いについては写真では判断できないため、現地で必ずチェックが必要です。カビの匂いは壁裏や床下に原因があることが多く、入居後も改善できないケースが多いため契約見送りの判断基準になります。

下水の匂いは水を流して消えるなら対処可能ですが、改善されない場合はクレームに直結するため見送りを推奨します。

**【室内チェック②】防音・音漏れの確認**

スタジオ運営における撤退理由の中で最も多いのが音のトラブルです。内見時には必ずスピーカーを持参し、実際の利用シーンに近い大音量で音を流してください。

確認場所は**廊下・隣室・上下階・建物の外**の4か所。目安は**70dB以下**です。スマホの無料デシベル測定アプリで簡易測定ができます。

音を流すだけでなく、**2人以上で行って実際に動いてみて、振動が下階に響かないか**まで確認できると安心です。

参考までに、僕の加古川の店舗は目の前が老人ホームなので、**70dB以下での利用に限定して**運営しています。

音漏れがひどい場合は、参入しないことを強く推奨します。出店した後に撤退するほうが、はるかに損失が大きいからです。

**【室内チェック③】床の素材と状態**

滑りすぎる床は転倒リスクがあり、利用者の怪我やクレームに直結します。目立つ傷・へこみ・ギシギシ音・ささくれがないかも確認してください。

床材ごとの扱いは次の通りです。

| 床材 | 判断 |
|---|---|
| フローリング / クッションフロア / フロアタイル | **そのまま使用可** |
| カーペット | 貸し会議室ならOK。ダンスには不向き |
| コンクリート / 畳 | **施工が必須。** 初期費用が大きく膨らむ |

なお床は**最悪張り替えられます。** 10万〜30万円程度で施工できるので、立地や家賃が抜群に良い物件であれば「張り替える前提で借りる」という判断もアリです。逆に、施工費で初期費用が膨らみすぎるなら**そもそも参入しない**という判断も検討してください。

**【室内チェック④】鏡の設置可否と壁の状態**

ダンススタジオでは最低3メートル以上の連続した壁面が必要です。窓や柱で壁が分断されないか確認し、壁への穴開けや鏡の貼り付けが可能かどうかを不動産業者に確認してください。

壁への穴あけが必要になるため、**使用の可否と原状回復の条件はセットで**不動産業者に確認しておきましょう。

古い壁紙の上から鏡を貼ると、**壁紙ごと剥がれて鏡が落下する危険**があります。壁紙が浮いていないかも見てください。

僕は基本的に**突っ張り式の鏡**を使っていますが、**天井の中が空洞になっていると突っ張り棒が効きません。** ここを見落とすと、フラットで広い良い壁だったのに鏡が立てられない、という致命的な事態になります。天井の状態も必ず確認してください。

**【室内チェック⑤】内見時に採寸を済ませる**

後日再訪して採寸するのは時間の無駄です。鏡を貼る面・天井の高さ・カーテンサイズ・照明・収納スペースなど、必要な箇所はすべてその場で測っておいてください。

メジャーよりレーザー距離計を使うと一瞬で正確に測れるため非常に便利です。

#### 室外のチェックリスト

**【室外チェック①】実際の駅からの距離**

図面上の徒歩1分は80m換算であり、信号・坂道・歩道橋は考慮されていません。実際に駅から歩いて所要時間を計測してください。大きな荷物を持った利用者にとっての負担感も意識して確認することが重要です。

**【室外チェック②】オートロックの有無**

オートロックはセキュリティが高い反面、無人運営の最大の障壁になり得ます。夜間に建物が閉鎖されると24時間営業ができないため、何時から何時まで出入り可能かを管理会社に必ず確認してください。毎回の解錠対応が必要な仕組みの場合は無人運営に向きません。

**【室外チェック③】鍵・周辺環境・ゴミ**

鍵の受け渡しはキーボックスが推奨です。ドアノブへの取り付けが可能かどうかも確認してください。周辺に一般住居・学習塾・静かなオフィスがある場合はクレームリスクが高まるため、繁華街やロードサイドを優先するのが無難です。事前にGoogleマップで周辺環境を確認しておくと内見前に候補を絞り込めます。

#### 契約前に確認すべき6つの条件

契約書に署名した後では変更できないため、必ず事前に書面で確認してください。

1. **営業可能時間**：24時間営業が可能かどうか
2. **音出し・振動の可否**：ダンス利用が認められているか、許容デシベル数はいくつか
3. **光回線の引き込み**：既存回線の有無、新規工事の可否（不要な場合はWiMAX等で対応可）
4. **床・壁への加工可否**：鏡の貼り付けやクッションフロアの施工が認められるか
5. **残置物・クリーニング費用**：前入居者の残置物撤去や入居前クリーニングが借主負担になっていないか
6. **事業譲渡の可否**：将来的な売却を見据えて賃貸借の譲渡が認められるか

#### 古い物件を選ぶ際の2つの注意点

鍵が回しにくい場合、利用者からのクレーム電話が頻発します。潤滑油は埃が固まり故障の原因になるためNGで、**鉛筆の芯を鍵の溝に擦り付ける**と改善できます。

下水の匂いが取れない場合は定期的にお湯を流して排水トラップに水を溜めておくことで対処できますが、改善できない物件は契約前に見送る判断も必要です。

#### ロードサイド物件が成立する3つの条件

駅から遠くても、以下の3条件が揃えば定期利用だけで予約が埋まる強力なビジネスになります。

- ロードサイドに面していること
- 広さ90平米以上であること
- 駐車場が複数台停められること

#### なぜ駅から遠くても勝てるのか

キッズスクールや大人向け教室・稽古事は、広いスペースが必要なため駅近の小箱では対応できません。また車移動が中心の地方では、駐車場がない駅近物件よりも広くて停めやすいロードサイド物件の方が選ばれやすくなります。こうした用途のお客様は毎週決まった曜日・時間帯に定期利用してくれるため、ストック型収入が非常に安定します。

#### 実際の運営事例

**2店舗目**として、家賃8万8千円・90平米・駐車場ありのロードサイド物件を実験的に出店しました。田舎なので、90平米に対して8万8千円という家賃はかなり安いです。

結果、**1週間7日のうち6日を定期利用で埋める**ことができ、**定期利用だけで月4〜5万円の利益**が発生しています。

時間制の単発利用も加えると**月7〜8万円の利益**になっています。収益が安定するまでに7〜8ヶ月かかりましたが、競合が少ないブルーオーシャン領域で、時間をかければ着実に黒字化できます。

### ① 鏡（ダンススタジオの命）

鏡はダンススタジオの中で最も重要な備品です。推奨は**突っ張り式の大型スタンドミラー**で、楽天で購入可能です。1枚あたり約2万5千〜2万6千円で、6枚揃えると十数万円程度になります。

貼るタイプは基本的に不要です。鏡の映りが悪いとリピート率に直接影響するため、備品リスト記載のものをそのまま購入することを推奨します。

### ② スピーカー

高スペックなものは不要で、4,000〜5,000円程度の安価なもので十分です。盗難リスクがあるため高額なものは避け、Bluetooth接続必須のシンプルなものを選んでください。Ankerのスピーカーが費用対効果の面でおすすめです。

### ③ 清掃用品（清潔感がリピート率を左右する）

最低限必要なものと、その用途は次の通りです。

| 備品 | 用途 |
|---|---|
| フロアモップ | お客様に利用後の清掃をしてもらうため |
| ウェットシート | フロアモップで取れない床の汚れをこすり落とす |
| クロス | 鏡拭き（ウェットシートで拭いた後にクロスで仕上げると汚れが取れやすい） |
| ゴミ箱・掃除機・ほうき | 基本の清掃 |
| 消臭スプレー | 下水などの匂い対策。僕は全店舗に必ず置いています |
| バケツ | 必須ではない。大掃除のときにあると便利 |

女性利用者が多いため清潔感は特に重要で、週1回の清掃業者への外注を推奨します。消耗品の買い出しも清掃業者に依頼すると運営が楽になります。トイレがある場合は芳香剤やクイックルワイパーも用意してください。

### ④ キーボックス

玄関のドアノブに設置する4桁以上のダイヤル式が推奨です。予約確定時に暗証番号をお客様に送り、無人で入室してもらう仕組みです。

暗証番号を勝手に変えられるトラブルや開かなくなるケースに備えて、**別の場所に予備ボックスを設置**しておくことを強く推奨します。

### ⑤ 遮光カーテン

プライバシー・室温・照明演出の3つの観点から必須の備品です。夏場は遮光なしで室内が非常に高温になり、照明演出も昼間は遮光なしでは機能しません。

サイズはレールの端から端に対して幅プラス5%のゆとりを持たせ、丈は窓の種類に応じて調整してください。オーダーカーテンは納品まで約2週間かかるため早めの注文が必要で、サイズが合えばニトリで購入するのが手軽です。

### ⑥ その他の備品

ヨガマット・ストレッチポール・バレエバーはダンススタジオでの要望が多いため用意しておくと予約が埋まりやすくなります。

大箱の場合は**卓球台（1台2万数千円）**を置いて卓球施設としても貸し出せます。また机・椅子をいくつか用意して棚にしまっておき、**会議室としても使えるようにすると稼働率が上がります。**「あって困る」ことはありません。

**Wi-Fiは必須です。** 貸し会議室でもダンススタジオでも学生の利用が多いため、高速回線を引いてください。なお予約管理用のタブレットを置く必要は特にありません。

**サーキュレーター**は、クーラーがついていても空気の循環が悪いと効きが悪くなるため、空調効率を上げる目的で有効です。特に夏場の冷却効率が大きく変わります。空気清浄機・加湿器は、どちらかというと貸し会議室向けです。

### ② 写真撮影のポイント

掲載写真の質は予約率に直結します。プロへの依頼が理想ですが、自分で撮る場合は以下を意識してください。

明るい時間帯に自然光を最大限活用し、広角レンズで部屋を広く見せることが基本です。撮影者の映り込みやゴミ・不要物が写らないよう清潔感を徹底してください。

撮影すべき対象は、室内全体・鏡や床などの設備詳細・建物外観・エントランス・廊下・トイレです。外観や入り口の写真はお客様が迷わず来られるようにするために特に重要です。

### ③ 料金設定

競合と比べて高すぎると予約が入らず、安すぎると品質を疑われ客層が悪化します。**最初は競合より10%程度安く設定し、レビューが溜まってきたら10%程度値上げしていく**のが基本戦略です。

平日は安く・休日は高く設定し、3時間・半日・1日などのパック料金で長時間利用を促してください。深夜・早朝を安く設定することで、検索サイトに「500円から」と表示されクリックのきっかけになります。

### ④ 設備・予約・キャンセル設定

設備はWi-Fi・エアコン・トイレ・電源に加え、鏡・音響・照明・三脚・スマホスタンドなどスタジオ特化の設備も漏れなく入力してください。

予約は即時予約を推奨し、最小予約時間は清掃時間を確保するために1時間以上に設定します。キャンセルポリシーは前日50%・当日100%が目安です。利用規約にはゴミの持ち帰りと軽い清掃の2点を必ず明記してください。

### ⑤ Googleカレンダー連携でダブルブッキングを防ぐ

インスタベース・スペースマーケット・自社決済の3つを別々に管理するとダブルブッキングのリスクが生じます。専用のGoogleアカウントを作成し、すべてのポータルサイトを同一のGoogleカレンダーに紐づけることで予約管理を完全自動化できます。

### ⑥ レビューを能動的に獲得する

レビューがなければ選ばれません。**最初の10件が最重要ミッション**です。オープン直後は知人に格安で利用してもらい正直なレビューを依頼する、利用後にメッセージでレビューを依頼する、コミュニティで相互レビューするといった方法で積極的に獲得してください。

レビューには必ず返信することで信頼度と予約率がさらに上がります。30件・50件と積み上げることで地域ナンバーワンや上位表示も狙えるようになります。

### ① ホームページの作り方：外注 vs 自作

クオリティを重視するなら30万円程度かけてプロに外注するのが理想で、SEO対策やデザインまで任せられます。初期費用を抑えたい場合は自作がおすすめで、修正や更新の自由度も高くなります。自作するなら**WordPressを最初から使っておく**ことを推奨します。

ペライチから始めると後でWordPressへ移行する手間が発生するため、最初からWordPressで構築しておいた方が長期的に楽です。

### ② SEO対策の基本

複雑なテクニックは不要で、「キーワード分析」と「競合分析」の2つに集中すれば十分です。「地域名×レンタルスペース」「地域名×レンタルスタジオ」といったキーワードで競合がどう上位表示されているかを分析し、同じキーワードをページタイトルや見出しに自然に盛り込んでください。

ブログは新店舗オープンやSNS開設の告知など簡単な内容で構いません。「兵庫県おすすめレンタルスタジオ」のようなまとめ記事や利用者のレビューを追加することで検索されやすくなります。

### ③ 集客の基本戦略：ポータルサイトから自社へ誘導する

まずはインスタベース・スペースマーケットで集客し、そこから**公式LINE・自社ホームページ・SNS**へ繋げることで利益率と集客力が上がります。認知も拡大していきます。

初回は知人にモニター利用してもらいレビューを獲得することを優先してください。初回割引・平日割・レビュー特典などを用意して心理的ハードルを下げ、リピート化につなげることが重要な戦略です。

### ④ 公式LINE × よやクルで自社決済の導線を確立する

公式LINEと連携できる自社予約システム**「よやクル」**を使うことで、ポータルサイトの手数料を大幅に削減できます。リッチメニューから予約・決済まで完結させられます。月額4,980円で最大5.5スペースまで管理でき、決済手数料は3.6%です。

インスタベースやスペースマーケットと比べて手数料が圧倒的に安く、顧客管理も可能なためリピート率が約30%向上します。**最終的には予約の8割を自社決済に移行させることが利益率最大化の目標**です。Googleカレンダーとの連携やPayPay・クレジットカード・銀行振込など複数の支払い方法にも対応しています。

- [よやクルのホームページはこちら](https://v3.yoyakul.com/)

### ⑤ 支払い方法は選択肢を多く用意する

- 現金（近隣限定・トラブル時の対応として）

## 集客と運営について

**新規集客はポータルサイトが9割！だからこそ重要なのはリピート施策**

> 🎥 **【動画17】集客と運営の黄金ルール**

**文字で読みたい方はこちら↓**

### ① 新規集客の現実：ポータルサイトが9割

新規集客はインスタベースとスペースマーケットのポータルサイトがほぼすべてを担います。両者の比率はインスタベースが8〜9割、スペースマーケットが1〜2割です。

**ポータルサイトなしでは勝てません。** これを理解した上で、ここを起点に「現地で公式LINEに誘導 → 自社決済でリピート」という流れを作るのが基本戦略です。

### ② リピート施策が重要な理由：手数料の差

インスタベースの手数料は35%、スペースマーケットは30%と非常に高く、利益を大きく圧迫します。一方、自社決済に誘導できれば手数料は**3.6%**まで下がります。

この差が手元に残る利益に直結します。

**ポータルサイトで集客 → 現地で公式LINEに誘導 → 2回目以降は自社決済でリピート。**

この流れを作ることが、収益改善の最重要施策です。手数料が30〜35%から3.6%になる、つまり**利益率が約30%改善する**ということです。

### ③ 公式LINE（自店舗のLINE公式アカウント）に登録してもらう

> ここで言う公式LINEは、**あなたが自分のスタジオ用に作るLINE公式アカウント**のことです。
> ポータル → 公式LINE → 自社決済、という導線の真ん中を担います。

来店したお客様に登録してもらうための施策として、僕が実際に使っているものです。

| 施策 | 内容 |
|---|---|
| 次回500円オフクーポン | 登録するだけで次回使えるクーポンを配布 |
| 公式LINE最安値保証 | 「今後、公式LINEからが一番安く予約できます」と明示 |
| Wi-Fiパスワードの限定配布 | 「LINEを登録して『Wi-Fi』と送ってください」→ 自動応答で返す |
| 鍵の開け方動画のLINE限定公開 | 入室方法をLINE経由でしか見られないようにする |

これらを組み合わせることで、**来店してくださった方の約7割がLINEに登録**してくれます。

登録してもらったら、次は**2回目の予約**です。
500円オフクーポンで**「2回目の壁」を突破する**ことが、顧客生涯価値（LTV）を最大化する上で決定的に重要になります。

さらにLTVを上げるために、接触回数を増やしていきます。

- 月1回程度の定期配信
- クリスマス割引、新春キャンペーンなど**季節イベントを口実にしたクーポン配信**

ここで予約が入らなかったとしても、**「そういえばあのスタジオがあったな」と思い出してもらえる**ので、次回の予約につながります。

**LINEの接触回数を最大化することが、そのまま売上と利益率の向上につながります。**

### ④ インスタグラムで定期予約を獲得する

インスタグラムは特に大箱スタジオでの定期予約獲得に有効です。「地域名×ダンス講師」などのキーワードで検索し、地域のダンス講師や教室運営者にDMで直接アプローチします。

場所を探している講師にとってこちらからの提案は渡りに船となり、定期利用につながるケースがあります。DM送信時はスタジオの広さ・鏡・音響などのスペックを明示してください。

待つのではなく、**こちらから提案するプッシュ型**であることがポイントです。場所を探している講師にとっては渡りに船なので、教室・道場などの定期顧客がつき、結果的に毎月の売上が安定します。

僕のアカウントは**フォロワー160数人**しかいませんが、それでも定期予約は数件取れています。地域限定で運用するなら、フォロワー数は関係ありません。自社スタジオのアカウントを作って、積極的に発信・アプローチしていきましょう。

- [弊社インスタグラムのアカウントはこちら](https://www.instagram.com/nono_studio_hyogo/)

→ フォロワー数は少ないですが、定期予約の受付もDM経由で取れています。

## 最後に

ここまでご覧いただき、本当にありがとうございます。

レンタルスタジオ事業は、派手なビジネスではありません。

一気に何千万円も稼げるような夢物語でもなければ、放置して完全に何もしなくていいものでもありません。

ですがその一方で、正しい物件を選び、正しい導線を作り、正しい運営を積み重ねていけば、**未経験からでも十分に黒字化を狙える、数少ない現実的なスモールビジネス**だと僕は思っています。

実際に僕自身も、最初から何もかも上手くいったわけではありません。

物件選定で悩んだこともありますし、問い合わせで断られたこともあります。
出してみたものの、思うように予約が入らず苦戦したこともありました。

それでも、試行錯誤を繰り返す中で確信したのは、
**レンタルスタジオ事業は「センス」ではなく「基準」で戦える**ということです。

だからこそ、このコンテンツでは、なるべく感覚論を排除して、

- どんな物件を選ぶべきか
- どこを見て判断すべきか
- どうやって集客し、どうやって利益を残すのか

という部分を、できる限り再現しやすい形でまとめました。

副業として月5万円の利益を作りたい方にとっても、
将来的に複数店舗へ拡大したい方にとっても、
この事業は十分に狙う価値があります。

最初の一歩は、決して大きなものじゃなくて大丈夫です。

まずは物件を見てみる。
競合を調べてみる。
1件問い合わせてみる。

それだけでも、確実に前に進みます。

この講座が、あなたにとってその最初の一歩を後押しするものになれば嬉しいです。

そしていつか、あなた自身のスタジオが安定して稼働し、
「始めてよかった」と思える未来につながることを心から願っています。

ぜひこの教材を何度も見返しながら、実際の行動に落とし込んでみてください。

あなたの挑戦を、心から応援しています。
