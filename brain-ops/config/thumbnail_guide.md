# 売れるサムネのルール

このファイルに書いたルールを、Claude（サムネの文言）と ChatGPT（サムネの絵）が毎回守ります。
「## 文言」の内容は Claude に、「## デザイン」の内容は ChatGPT に渡します。
書き換えたら Bot を再起動すると反映されます（次に作る下書きから）。

## 文言

Brain で売れるサムネは、次の6要素を入れる。catch・sub・badges を使って、できるだけ多くの要素を盛り込む。

1. 完全性：「完全網羅」「全手順」「これ1本で」「総まとめ」など、この記事だけで全部わかることを伝える
2. 再現性：「実績ゼロOK」「顔出しなし」「副業・初心者でもOK」「スマホだけ」など、読者の条件でもできることを伝える（材料と記事の内容に合うものだけ）
3. 速攻性：「初月から」「最短○日」「今日から」など、成果や行動までの早さを伝える
4. 具体性：ぼかした数字より具体的な数字。「月収○万円」より「1ヶ月で○○万円」「時給○,○○○円」のように、桁まで具体的に書く
5. 文字量の多さ：最近の Brain は文字量の多いサムネのほうが売れる。catch に加えて sub と badges（短い訴求のタグ）を3〜5個入れて、情報量を多くする
6. アイコン：サムネに書き手のアイコンを入れる（システムが自動で右下に合成するので、文言では気にしなくてよい）

数字のルール（大事）：
- 具体性・速攻性の数字（金額・期間・件数・時給など）は、運営者の材料に書かれている本当の実績・事実だけを使う。材料に無い数字は作らない
- 実績の金額は材料の数字を半分に控えめにして書く（例: 1ヶ月で220万円 → 1ヶ月で110万円、初月から時給1万円 → 初月から時給5,000円）
- 材料に数字が無いときは、数字を使わずに具体的な言葉（手順の数、対象、場面など）で具体性を出す
- 「誰でも稼げる」「絶対」「必ず」のように成果を保証する言い方はしない。再現性は「実績ゼロOK」のように条件で伝える

## デザイン

- 文字量が多くても読めるように、メインの見出しを一番大きく、補足とタグは小さめにして、強弱をはっきりつける
- タグ（badges）は、角丸の帯や吹き出しの中に入れて目立たせる
- 右下の角（横260px・縦260pxくらい）は、書き手のアイコンを後から合成するので、文字や重要な絵を置かずに空けておく
