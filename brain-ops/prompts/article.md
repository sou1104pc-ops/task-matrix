# 記事の型
Brain の記事は「無料部分」と「有料部分」に分かれます。本文の途中に <p>[[PAYWALL]]</p> を1回だけ置き、そこより前が誰でも読める無料部分、後ろが購入者だけが読める有料部分です。

## 無料部分（1,500〜3,000字）
1. 読者の悩みを「」で1〜2個示して共感する
2. その悩みが起きる理由・よくある遠回り（ここは無料でも価値がある内容にする）
3. この記事で手に入るもの：有料部分の内容を箇条書きで具体的に（「○○の手順」「○○のチェックリスト」など）
4. こんな人におすすめ／おすすめしない人（向かない人も正直に書く）
5. 有料部分の目次（有料部分の <h2> と同じ見出しを <ul> で並べる）

## 有料部分（8,000〜15,000字）
- 価格に見合う、具体的で実務で使える内容。抽象論や精神論で字数を埋めない
- 手順・判断基準・テンプレート・チェックリスト・具体例など、読んだらすぐ行動できる形にする
- <h2> で4〜7章に分け、必要なら <h3> で細かく分ける
- 最後に「まとめ」と「次にやること」を置く

# 厳守ルール（違反すると公開できません。Brain の審査ガイドラインにも関わります）
- 書き手の架空の実体験・実績・収益を書かない（「私はこの方法で月100万円」「私が支援した方は」などは禁止）。一般論・考え方として書く
- 「誰でも」「絶対」「必ず」「確実に」「100%」「放置で」など、成果を保証する・誇大な表現を使わない
- 収入や成果の具体額を約束しない。目安を書くときは「目安」「一般的に」と明記する
- 出典のない具体的な統計・件数・割合を書かない
- 実在しない購入者の声・口コミ・レビューを作らない
- 外部サイトへのリンクや、LINE登録・別商品への誘導を本文に入れない（特典の案内はシステムが有料部分に差し込みます）
- 材料に書かれていない実績・数字・体験談を足さない。材料にある運営者自身の経験は、材料に書かれた範囲でなら使ってよい
- {achievement_rule}
- 無料部分で煽りすぎない。有料部分に書いていないことを無料部分で約束しない
- やわらかい「です・ます」調

# 図解のルール
- figures は5〜8個（有料記事なので、文字だけの区間が長く続かないように多めに入れる）
- type は checklist（確認ポイント）/ steps（手順）/ compare（比較表）/ grid（要点4つのカード）から、その段落の内容に合うものを選ぶ。同じ type を3回以上続けない
- 図は本文の要点をまとめ直したもの。本文に無い情報・数値・社名を図に入れない（厳守ルールは図にも適用）
- 各図は本文中に <p>[[FIG:id]]</p> として1回ずつ置く。無料部分に1〜2個、有料部分に4〜6個
- 有料部分では、<h2> の章ごとに1個を目安に置く（章の説明のあと、まとめとして見せる位置）
- [[FIG]] と [[PAYWALL]] は必ずそれだけで1つの <p> にする
