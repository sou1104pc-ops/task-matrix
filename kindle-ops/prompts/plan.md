# 本が読まれる公式：PV × CTR × CVR
- PV（本を見つけてもらう）＝ Amazon の検索で上に出ること。タイトルと7つのキーワード欄で決まる
- CTR（クリックしてもらう）＝ 表紙とタイトル。無名の著者の本は表紙で8割決まる
- CVR（読んでもらう）＝ 紹介文（目次・この本で得られること・他にない理由）
直す順番は CTR → CVR → PV。表紙とタイトルを一番大事にしてください。

# タイトルの作り方
- 読者が Amazon の検索窓に打ちそうなキーワード（main_keyword）を**タイトルの一番前**に入れる。例：「Twitterの伸ばしかた」
- 売れている本があれば、そのタイトルに使われているキーワードに寄せる（コバンザメ戦略）。ただしタイトルを丸ごと真似しない・他の本の名前や著者名は入れない
- 短くて言い切る形に。くわしい説明はサブタイトルに回す（サブタイトルにも関連キーワードを入れる）
- 「必ず」「絶対」「100%」「誰でも稼げる」のような結果を約束する言葉は使わない
- タイトルに年号を入れない

# 7つのキーワード欄
- 7個とも埋める。1個あたり {keyword_max}字以内
- 1つの欄に関連する言葉をスペース区切りで複数入れてよい（例：「ツイッター フォロワー 増やし方 SNS運用」）
- タイトルに入っている言葉はくり返さない。読者が検索しそうな言い換え・悩み・関連ジャンルを入れる
- 他の著者名・他の本のタイトル・「Kindle Unlimited」「無料」「ベストセラー」などは入れない（KDPの規約で禁止）

# 紹介文（description_html）
次の順で、全体で1,500〜2,500字。使えるタグは <p> <b> <br> <ul> <li> のみ。
1. 読者の悩みに呼びかける2〜3行
2. この本で何がわかるか（箇条書き3〜5個）
3. 目次（章の見出しをそのまま。見出しは「〇〇しただけで…？」のように中身をあえて少し隠して、読みたくなる形にする）
4. 他の本にはない点（著者メモに体験があればそれを。無ければ「手順を一冊にまとめた」などの事実だけ）
5. こんな人におすすめ（箇条書き）
特典・レビューのお願い・他の本の宣伝・URLは入れない。

# 表紙（cover）
- catch：表紙の一番大きな文字。main_keyword を必ず含める。2〜3行、改行は単語の切れ目に \n、1行8字以内。いちばん目立たせたい言葉を【】で囲む（1か所）
- top：catch の上の小さな文字（読者への呼びかけ・20字以内）
- sub：catch の下の補足（サブタイトルの要点・30字以内）
- points：表紙の下に並べる「この本でわかること」3個（各14字以内）
- badge：右上の丸に出す短い言葉（例：「完全\n図解」「初心者\nOK」。2行・1行4字以内）
- color：本の雰囲気に合う色を1つ（orange / blue / green / red / navy / pink のどれか）

# 章立て（chapters）
- 6〜8章。全体の本文は合計 約{book_chars}字（はじめに・おわりにを除く）
- 各章に、その章で書くことの要点（points）を4〜6個。具体的な手順・判断基準・よくある失敗・チェックリストが入るようにする
- 各章のタイトルも目次としてそのまま紹介文に載るので、読みたくなる言葉にする

# はじめに（intro_html）
1,000〜1,500字。この本で何が得られるかを書く。紹介文の「試し読み」にもなるので、読み進めたくなる形に。
使えるタグは <h2> <h3> <p> <ul> <ol> <li> <b> のみ（最初に <h2>はじめに</h2>）。

# おわりに（outro_html）
500〜800字。次の一歩を1つだけ示して締める。<h2>おわりに</h2> から始める。

# 厳守ルール
- 架空の体験談・架空の実績・架空の数字を書かない。「私も〜しました」「〇〇万円稼げた」は著者メモにある事実だけ
- 出典のない統計の数字（〇〇%の人が、〇〇万人が）を書かない
- 法律・税金・医療・投資の話は「最新の情報は公式サイトで確認してください」と添える
- 他の本・他の著者の文章を写さない
