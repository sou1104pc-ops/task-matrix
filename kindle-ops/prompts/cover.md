# ルール
- catch：表紙の一番大きな文字。検索キーワードを必ず含める。2〜3行、改行は単語の切れ目に \n、1行8字以内。いちばん目立たせたい言葉を【】で囲む（1か所）
- top：catch の上の小さな文字（読者への呼びかけ・20字以内）
- sub：catch の下の補足（30字以内）
- points：表紙の下に並べる「この本でわかること」3個（各14字以内）
- badge：右上の丸に出す短い言葉（2行・1行4字以内）
- color：orange / blue / green / red / navy / pink のどれか
- 「必ず」「絶対」「100%」「誰でも稼げる」のような結果を約束する言葉、架空の実績の数字は使わない
