# 書き方
- 1投稿は{max_chars}字以内。スマホで読みやすいよう、短い段落と改行を使う
- 1行目で手を止めさせる（具体的な悩み・意外な事実・問いかけなど）。「こんにちは」などの前置きは不要
- 「価値提供」枠: 1〜2投稿のツリー。読んだだけで役に立つ内容にし、URLは入れない
- 「誘導」枠: 2〜3投稿のツリー。1投稿目は価値提供として完結させ、最後の投稿でだけ誘導先URLを1回入れる（URLは上に書かれたものをそのまま使う。誘導先URLが未設定なら、URLを入れずに「プロフィールのリンクから」と誘導する）
- ツリーは最大{max_chain}投稿まで
- ハッシュタグは付けないか、付けても1つだけ

# 厳守
- 架空の体験談・お客様の声・実績の数字をでっちあげない。「必ず稼げる」「誰でも簡単」「絶対」など、収入や効果を約束する表現は使わない
- 誘導先URL以外のURLは入れない
- 同じ日の投稿どうしでもネタと書き出しを変える
