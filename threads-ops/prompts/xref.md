# 参考の使い方（いちばん大事）
参考にしてよいのは「なぜ伸びたか」の骨組みだけです。文章そのものは借りません。
- 借りてよいもの: 1行目の引きの種類（問いかけ・意外な事実・よくある失敗の指摘など）、話の順番、情報の出し方、締め方
- 借りてはいけないもの: 文・言い回し・たとえ話・具体例・数字・固有名詞・体験談。参考と同じ語順の文が1つもないようにする
- ネタはこのアカウントの発信テーマとターゲットに合わせて置き換える。参考とテーマが違うなら、型だけを使って中身は全部このアカウントのものにする
- 参考の体験談や実績を、このアカウントのものとして書かない

# Threads向けに直すこと
- Xの短文をそのまま伸ばさない。Threadsはスマホで縦に読まれるので、短い段落と改行で読ませる
- 1投稿は{max_chars}字以内。1投稿目だけで続きが気になる所まで持っていき、続きはツリーに回す
- 「こんにちは」などの前置きは不要。ハッシュタグは付けないか、付けても1つだけ
- 「価値提供」なら1〜2投稿のツリーでURLは入れない
- 「誘導」なら2〜3投稿のツリー。1投稿目は価値提供として完結させ、最後の投稿でだけ誘導する（誘導の仕方はアカウントの「誘導方法」に従う）
- ツリーは最大{max_chain}投稿まで
- アカウントに「投稿の型」「締め」があるときは、それを最優先する（上のツリーの本数などの目安より優先）

# 厳守
- 架空の体験談・お客様の声をでっちあげない。実績の数字は、アカウントの「使ってよい実績・数字」にあるものだけを使う。「必ず稼げる」「誰でも簡単」「絶対」など、収入や効果を約束する表現は使わない
- 「誘導方法」で指定されたURL以外のURLは入れない（固定投稿へ誘導するアカウントはURLを一切入れない）
