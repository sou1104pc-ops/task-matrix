# 有料記事の考え方
- 100円を払った読者が「手元に置いておきたい」と思える、まとまった実用資料にする。無料記事の寄せ集めにしない
- 有料部分の中心は、チェックリスト・手順表・スケジュール表・判断の基準・質問の例文・書き方のテンプレートなど、そのまま使える道具にする
- 有料部分にはアフィリエイトのリンクを一切入れない。案件名の宣伝もしない（内部リンクの「あわせて読みたい」は入れてよい）

# 構成
本文は無料部分と有料部分に分け、その境目に <p>[[PAID]]</p> を1回だけ置く。

## 無料部分（2,000〜3,000字）
1. 冒頭の段落（120字前後）：メインキーワードを入れて「この記事で何が手に入るか」をまとめる
2. 読者の悩みを「」で2〜3個示して共感し、なぜ一人で進めると失敗しやすいのかを書く
3. 有料部分の目次：各章で何が手に入るかを箇条書きで具体的に示す（「○○チェックリスト（20項目）」など）
4. 相談先の案内：紹介案件がこの読者に合う理由を、上に書かれた特徴の範囲で書き、
   「▼ 完全無料で相談できます」の一文のあとに案件リンクを置く（上の cta 文言をリンクテキストにする）
5. 無料部分の最後の段落は必ず「※本記事はアフィリエイト広告（PR）を含みます。」にする（有料部分を買わない人にも見える位置）

## 有料部分（8,000〜12,000字）
- 見出し（<h2>）ごとに1つの道具を渡す。<h3> で細かく分け、箇条書きと <strong> を多めに使う
- 図解を2〜3個入れる（下の「図解のルール」）
- 最後に「よくある質問」の <h2> と、Q&Aを3〜5個（<h3> に質問、<p> に答え）
- 最後の段落に「※{as_of}時点の情報です。制度や条件は変わることがあるため、最新の情報は各サービスのサイトで確認してください。」を置く

# 書き方
- 専門用語は使ったらすぐ中学生でも分かる言葉で言いかえる。一文は短く（目安40字以内）、1段落は2〜3文
- タイトルは28〜40字で「【完全攻略】」から始め、メインキーワードを前半に入れる

# 厳守ルール（違反すると公開できません）
- 書き手の架空の実体験・実績を書かない（「僕も多くの相談を受けてきました」「私が支援した方は」などは禁止）。一般論として書く
- 例を出すときは「たとえば、こんなケースがあります」のように、よくある例だと分かる書き方にする。体験談・お客様の声は作らない
- 出典のない具体的な統計・件数・割合を書かない。年収などの目安を書くときは「目安」「一般的に」と明記する
- 「絶対」「必ず」「確実に」「100%」などの断定・誇大表現を使わない。「これで必ず内定」のような約束をしない
- 紹介案件の特徴は上に書かれた内容の範囲で書き、それ以上を創作しない

# 図解のルール
- figures は2〜3個。type は checklist（確認ポイント）/ steps（手順）/ compare（比較表）
- 図は本文の要点をまとめ直したもの。本文に無い情報・数値・社名を図に入れない
- 各図は本文中に <p>[[FIG:id]]</p> として1回ずつ置く。図の直前は <p> の段落にする
