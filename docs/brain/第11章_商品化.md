# 第11章 商品化

- 0. この章の位置づけ
  - この章がいちばん大事
    - 教材を作ること自体は、これまでの章に沿ってやれば誰でもできる
    - 制作フェーズは再現性が高く、差がつきにくい
    - 本当に差がつくのは「いかに売れるか」
  - 売れるかどうかを左右する2大要素
    - 最初の値段（価格設定）
    - サムネイル
  - この章で扱わないこと
    - 裏アルゴリズム（重要ではあるが、この章では解説しない）

- 1. 最初の値段
  - 最初にいくらで出すかで、その後の売れ行きが変わる
  - 【要追記】推奨の価格帯と決め方
  - 【要追記】値上げ・価格変更のタイミング
  - 単品の売上だけで完結させない前提で決める（→「3. 1本売って終わりにしない」へ）

- 2. サムネイル
  - サムネイルで売上は大きく変わる
  - 売れるサムネの6要素
    - 要素①【後日追記】
    - 要素②【後日追記】
    - 要素③【後日追記】
    - 要素④【後日追記】
    - 要素⑤【後日追記】
    - 要素⑥【後日追記】
  - 作り方：ChatGPTに作ってもらうのが今いちばんやりやすい
    - STEP1：Brainなどで売られている「これいいな」と思うサムネを集める
    - STEP2：それをベースにChatGPTに作ってもらう
    - STEP3：色などを変えて、自分の教材用に寄せる
    - ポイント：ゼロから作らない。お手本ベースが最短
    - ポイント：仕上げに「6要素」を満たしているかチェックする

- 3. 1本売って終わりにしない（収益の導線）
  - 「100円で1個売れて100円」では美味しくない
  - 打ち手A：オプトインアフィリエイトを使う
    - 案件はこちらで紹介する（講座内で共有）
  - 打ち手B：特典を使って公式LINEに引っ張る
    - 教材の中に特典を置く
    - 特典の受け取り先を公式LINEにする
    - 公式LINE・メルマガの中で商品を売る
  - ここまで作れたらめちゃくちゃ強い
    - 教材の売上＋その後ろの売上が乗る
    - 1回の販売がリスト（資産）として残る

- 4. 特典の作り込み
  - 特典は結構豪華にしておく
  - 効果1：教材そのものが売れやすくなる
  - 効果2：公式LINEに登録してもらいやすくなる
  - 効果3：オプトインアフィリエイトにも登録してもらいやすくなる
  - 「なんとなく付ける」ではなく、意識して設計するポイント

- 5. この章のアクション
  - 価格を決めた
  - お手本にするサムネを集めた
  - ChatGPTでサムネを作り、6要素でチェックした
  - 特典を用意した（豪華さを確認）
  - 公式LINEを設置し、特典の受け取り導線をつないだ
  - オプトインアフィリエイトの案件に登録した
  - 公式LINE・メルマガでの販売の流れを用意した
