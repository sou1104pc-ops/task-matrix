# Brain 講座 マインドマップ原稿

章ごとの構成を Markdown で管理し、そこから XMind 用ファイルを生成する。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `第11章_商品化.md` | 編集する原本。ここだけ直せばよい |
| `第11章_商品化.opml` | XMind 取り込み用（自動生成） |
| `第11章_商品化.xmind` | XMind ファイル本体（自動生成） |
| `build_mindmap.py` | `.md` から `.opml` / `.xmind` を生成 |

## 更新のしかた

1. `第11章_商品化.md` を編集する
2. 再生成する

```bash
python3 docs/brain/build_mindmap.py "docs/brain/第11章_商品化.md"
```

## XMind への取り込み

- `.xmind` … そのままダブルクリックで開く
- `.opml` … XMind の「ファイル → インポート → OPML」
- `.md` … XMind の「ファイル → インポート → Markdown」（バージョンによっては非対応）

## Markdown の書き方ルール

- `# 見出し` … ルートトピック（1ファイルに1つ）
- `- 項目` … トピック。インデント2スペースで1階層深くなる

```markdown
# 第11章 商品化

- 大項目
  - 中項目
    - 小項目
```

## 記号の意味

- `【後日追記】` … 内容が確定したら差し替える箇所
- `【要追記】` … 具体的な数字・手順をこれから入れる箇所
